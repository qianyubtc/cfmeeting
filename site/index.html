功能

零门槛不注册、不配置、不用自己的服务器，输入名字就能开会。
全平台一个会议室桌面、安卓、iOS 轻应用、网页，用同一个会议号互通。
完整会议能力宫格视图、共享屏幕、聊天、参会者管理、投票、等候室、分组讨论、网络研讨会。
邀请很方便会议号、链接、二维码、系统分享；任何人用浏览器点链接就能进。
中文界面包含会议内所有提示的简体中文语言包，随时切英文。
开源MIT 协议，所有代码公开，欢迎二次开发。

截图

它是怎么做到“没有后端”的

会议能力来自 Cloudflare RealtimeKit。桌面版和安卓版直接调用 Cloudflare 公开的演示接口创建 / 加入会议，会议界面在本地用 RealtimeKit UI Kit 的组件拼装并汉化。

网页版是纯静态文件：受浏览器跨域限制，加入会议时会把官方会议页面内嵌进来，创建会议则在官方页面完成后把链接粘贴回来生成邀请。

因此整个项目没有自己的服务器，也不需要任何账号。代价是：会议运行在 Cloudflare 的演示账号下，请只用于学习、测试和演示。
